# Análise de Vendas com Python

## Sobre o projeto

Este projeto foi desenvolvido como parte da aplicação prática dos conhecimentos adquiridos na trilha GitHub Foundations.

O objetivo é realizar uma análise de dados de vendas utilizando Python e a biblioteca Pandas, gerando informações que podem auxiliar na interpretação do desempenho dos produtos e das vendas.

## Objetivos

O projeto realiza análises para identificar:

* Faturamento total;
* Quantidade total de produtos vendidos;
* Ticket médio;
* Produto mais vendido;
* Produto com maior faturamento;
* Faturamento por produto;
* Faturamento por categoria;
* Faturamento por mês;
* Desempenho dos produtos.

## Tecnologias utilizadas

* Python
* Pandas
* Git
* GitHub
